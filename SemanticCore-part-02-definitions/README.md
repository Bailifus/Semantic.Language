# SemanticCore — Part 02: Definitions

Этот пакет содержит канонический машинно-ориентированный реестр терминов.
Каждый нормативный термин имеет стабильный идентификатор `DEF-xxx` и краткое
определение. RFC предоставляют человеко-ориентированное объяснение и
нормативные требования.

Правила приоритета и взаимных ссылок определены в `Definitions/Definitions.md`.
Никаких самостоятельных аксиом, ограничений или правил вывода здесь нет.
