# RFC-026: Deprecation Policy

Status: Draft

## Purpose

Определить единые требования к объявлению устаревания элементов Semantic Core.

## Scope

Документ описывает только правила объявления устаревания.

## Definition

Deprecation — объявление о том, что элемент не рекомендуется
для новых реализаций, оставаясь определённым спецификацией.

## Normative Requirements

DPP-001 Устаревание должно объявляться явно.

DPP-002 Причина устаревания должна быть документирована.

DPP-003 Устаревший элемент не изменяет свою семантику.

DPP-004 Реализации должны иметь возможность распознавать устаревшие элементы.

DPP-005 Semantic Core не требует обязательного удаления устаревших элементов.

## Non-goals

- сроки удаления;
- миграция реализаций;
- управление версиями.

## Rationale

Явная политика устаревания позволяет эволюционировать стандарту,
не нарушая совместимость существующих моделей.
