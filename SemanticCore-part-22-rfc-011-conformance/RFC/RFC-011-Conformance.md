# RFC-011: Conformance

Status: Draft

## Purpose

Определить требования, которым должна удовлетворять реализация,
чтобы считаться совместимой с Semantic Core.

## Scope

Документ определяет критерии совместимости реализации.
Производительность, внутреннее устройство и язык реализации не рассматриваются.

## Definition

Conformance — соответствие реализации нормативным требованиям Semantic Core.

## Normative Requirements

CFR-001 Реализация должна поддерживать все обязательные семантические примитивы.

CFR-002 Реализация должна сохранять семантику при преобразовании между внутренним
представлением и Canonical Text, а также при производном преобразовании между
Canonical Text и Canonical Diagram. Canonical Text остаётся нормативным источником.

CFR-003 Реализация не должна вводить скрытые семантические зависимости.

CFR-004 Реализация должна сохранять адресуемость всех семантических элементов.

CFR-005 Реализация может расширять функциональность только без нарушения требований Semantic Core.

## Non-goals

- скорость работы;
- требования к памяти;
- пользовательский интерфейс;
- язык программирования.

## Rationale

Единые критерии совместимости позволяют создавать независимые реализации,
способные обмениваться семантическими моделями без потери смысла.
