# Manifest

## Semantic scope

This archive fixes only the constitutional principles of the project.

## Included decisions

- Semantic Core is a standard, not merely a language or implementation API.
- Meaning exists only in the Semantic Model.
- Canonical Text and Canonical Diagram are canonical serializations.
- Presentation is non-semantic and may hide but not destroy semantics.
- Level of Detail reveals existing semantics.
- The Core is minimal, compositional, theory-neutral, and technology-independent.
- New primitives require demonstrated necessity.
- Axioms must be independent; derivable claims belong to derived properties.
- Independent implementation convergence is the standardization goal.
- Work is preserved as small, versioned, non-overwritten archives.

## Explicitly deferred

- Primitive definitions
- Formal axioms
- Invariants
- Derived properties
- Decision records
- Canonical text grammar
- Canonical diagram rules
- Conformance tests
- Examples
