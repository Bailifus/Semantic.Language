# RFC-018: Model Evolution

Status: Draft

## Purpose

Определить правила изменения Semantic Model без нарушения её семантики и совместимости.

## Scope

Документ описывает требования к эволюции модели.

## Definition

Model Evolution — процесс изменения Semantic Model с сохранением её
семантической корректности.

## Normative Requirements

ME-001 Изменения не должны нарушать семантику существующих элементов.

ME-002 Совместимые изменения должны сохранять возможность чтения существующих моделей.

ME-003 Несовместимые изменения должны быть явно идентифицируемы.

ME-004 Эволюция не должна изменять смысл неизменённых элементов.

ME-005 История изменений не является частью Semantic Core.

## Non-goals

- контроль версий;
- миграции данных;
- системы управления изменениями.

## Rationale

Эволюция модели позволяет развивать спецификации без разрушения
совместимости между независимыми реализациями.
