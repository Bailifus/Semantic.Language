# RFC-009: Canonical Text

Status: Draft

## Purpose

Определить требования к каноническому текстовому представлению Semantic Model.

## Scope

Документ описывает только канонический текст.
Форматы обмена, сериализация и хранение не рассматриваются.

## Definition

Canonical Text — нормативное текстовое представление Semantic Model,
достаточное для полного восстановления её семантики.

## Normative Requirements

CT-001 Каждый семантический элемент должен иметь однозначное текстовое представление.

CT-002 Канонический текст должен содержать всю семантически значимую информацию.

CT-003 Представление не должно зависеть от порядка визуализации.

CT-004 Две эквивалентные Semantic Model должны иметь канонически эквивалентное текстовое представление.

CT-005 Потеря семантики при преобразовании в Canonical Text недопустима.

## Non-goals

- человеко-ориентированный синтаксис;
- компактность;
- оптимизация хранения;
- конкретный формат файлов.

## Rationale

Канонический текст является нормативной формой обмена семантикой между независимыми реализациями.
