# RFC-019: Interoperability

Status: Draft

## Purpose

Определить требования к обмену Semantic Model между независимыми реализациями.

## Scope

Документ описывает требования к совместимости при обмене моделями.

## Definition

Interoperability — способность независимых реализаций обмениваться
Semantic Model без потери семантики.

## Normative Requirements

IO-001 Обмен не должен приводить к потере семантически значимой информации.

IO-002 Реализации должны использовать Canonical Text либо эквивалентное представление.

IO-003 Любые преобразования должны сохранять Semantic Equivalence.

IO-004 Расширения должны передаваться таким образом, чтобы базовая модель оставалась корректно интерпретируемой.

IO-005 Отсутствие поддержки расширения не должно препятствовать чтению базовой Semantic Model.

## Non-goals

- транспортные протоколы;
- сетевые API;
- форматы контейнеров;
- механизмы синхронизации.

## Rationale

Interoperability обеспечивает обмен моделями между независимыми инструментами
без зависимости от конкретной реализации.
