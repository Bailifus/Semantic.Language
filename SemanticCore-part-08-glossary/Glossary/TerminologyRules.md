# Terminology Rules

TR-001 Один нормативный термин — одно каноническое значение и один `DEF-xxx`
идентификатор.

TR-002 Не использовать синонимы для нормативных терминов.

TR-003 Термины Theory, Domain, Entity, Statement, Statement Instance, Role,
Value, Constraint используются без переопределения.

TR-004 Если вводится новый нормативный термин, он должен быть добавлен в
`Definitions.md` и связан с определяющим RFC взаимными ссылками.

TR-005 Glossary является навигационным указателем и не имеет самостоятельной
дефиниционной силы.

TR-006 При расхождении источников значение термина определяется в следующем
порядке: `Definitions.md` задаёт идентичность и краткий основной смысл термина;
соответствующий RFC задаёт подробное нормативное поведение; противоречие между
ними считается дефектом спецификации и должно быть устранено.
