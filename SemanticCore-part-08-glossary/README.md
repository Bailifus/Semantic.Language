# SemanticCore — Part 08: Glossary

Навигационный указатель терминов и правила терминологии.

Glossary предназначен для быстрого поиска человеком и не является независимым
источником определений. Канонический реестр находится в Part 02: Definitions;
подробные объяснения и нормативные требования находятся в RFC.
