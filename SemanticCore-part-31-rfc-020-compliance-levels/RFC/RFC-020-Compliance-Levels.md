# RFC-020: Compliance Levels

Status: Draft

## Purpose

Определить единые уровни соответствия реализации требованиям Semantic Core.

## Scope

Документ определяет только уровни соответствия и правила их заявления.

## Definition

Compliance Level — формализованный набор требований, которым соответствует
конкретная реализация.

## Normative Requirements

CL-001 Реализация должна явно указывать заявляемый уровень соответствия.

CL-002 Каждый более высокий уровень должен включать требования всех предыдущих.

CL-003 Уровень соответствия определяется только нормативными требованиями RFC.

CL-004 Реализация не должна заявлять уровень, если хотя бы одно обязательное
требование этого уровня не выполняется.

CL-005 Дополнительные возможности не повышают уровень соответствия сами по себе.

## Suggested Levels

- Core
- Extended
- Full

## Non-goals

- сертификация;
- процесс тестирования;
- лицензирование;
- коммерческие программы соответствия.

## Rationale

Стандартизованные уровни позволяют различным реализациям одинаково
интерпретировать заявления о совместимости.
