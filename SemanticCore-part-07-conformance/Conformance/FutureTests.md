# Future Conformance Tests

The identifiers in this file are non-normative placeholders for future test
cases. They intentionally use the `FCT-*` prefix so they cannot be confused
with normative requirement identifiers such as `CT-*` (RFC-009) or `TS-*`
(RFC-021).

FCT-003 Statement Instance as Value
