# RFC Authoring Rules

RA-001 Один RFC — одна тема.

RA-002 Нормативные требования используют SHOULD, MUST, MAY.

RA-003 Все новые термины должны ссылаться на Glossary.

RA-004 Если RFC меняет ранее принятое решение, он обязан ссылаться на соответствующий DEC.

RA-005 Каждый RFC обязан содержать разделы
'Rejected Alternatives' и 'Non-goals'.

RA-006 Примеры не являются нормативными, если явно не указано обратное.

RA-007 Префикс нормативных идентификаторов каждого RFC должен быть уникален
в пределах активного корпуса спецификации. Ненормативные элементы не должны
использовать префиксы, зарезервированные за нормативными требованиями.
