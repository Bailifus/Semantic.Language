# RFC-016: Addressability

Status: Draft

## Purpose

Определить требования к адресуемости элементов Semantic Core.

## Scope

Документ описывает только требования к адресуемости.

## Definition

Addressability — возможность однозначно ссылаться на семантический элемент
в пределах Semantic Model.

## Normative Requirements

AD-001 Каждый адресуемый элемент должен иметь идентификатор.

AD-002 Идентификатор должен быть устойчивым в пределах данной Semantic Model.

AD-003 Адресуемость не определяет идентичность элемента.

AD-004 Адресуемость должна сохраняться при преобразовании между внутренним
представлением и Canonical Text, а также при производном преобразовании между
Canonical Text и Canonical Diagram.

AD-005 Механизм формирования идентификаторов не регламентируется Semantic Core.

AD-006 Два элемента с различными идентификаторами считаются различными
элементами Semantic Model, пока Theory явно не установит их семантическую
идентичность посредством Statement Instance.

AD-007 Утверждение семантической идентичности не должно изменять или устранять
адресуемость участвующих элементов.

## Non-goals

- глобальная уникальность;
- генерация идентификаторов;
- жизненный цикл идентификаторов;
- распределённые системы.

## Rationale

Адресуемость является фундаментом ссылочной целостности и взаимосвязи
семантических элементов без навязывания конкретной реализации. Презумпция неидентичности позволяет
реализации сохранять элементы раздельно, не делая семантических выводов по
сходству их структуры или представления.
