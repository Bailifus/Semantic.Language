# RFC-025: Extension Lifecycle

Status: Draft

## Purpose

Определить состояния жизненного цикла расширений Semantic Core.

## Scope

Документ описывает только модель состояний расширений.

## Definition

Extension Lifecycle — набор состояний, через которые может проходить
расширение в процессе разработки и эксплуатации.

## Normative Requirements

EL-001 Расширение может иметь объявленное состояние жизненного цикла.

EL-002 Изменение состояния не должно изменять семантику опубликованной спецификации.

EL-003 Реализация должна иметь возможность определить состояние расширения.

EL-004 Semantic Core не требует обязательного прохождения всех состояний.

EL-005 Конкретный процесс управления жизненным циклом не регламентируется.

## Suggested States

- Draft
- Experimental
- Stable
- Deprecated
- Archived

## Non-goals

- процесс утверждения;
- управление версиями;
- публикация релизов.

## Rationale

Единая модель состояний помогает различным реализациям одинаково
интерпретировать зрелость расширений.
