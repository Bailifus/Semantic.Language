# RFC-017: Semantic Equivalence

Status: Draft

## Purpose

Определить критерии семантической эквивалентности Semantic Model.

## Scope

Документ определяет только семантическую эквивалентность моделей.

## Definition

Semantic Equivalence — отношение между двумя Semantic Model,
означающее, что они выражают одну и ту же семантику независимо
от внутреннего представления.

## Normative Requirements

EQ-001 Эквивалентность определяется семантикой, а не реализацией.

EQ-002 Различия внутреннего хранения не влияют на эквивалентность.

EQ-003 Эквивалентные модели должны допускать взаимное преобразование
без потери семантики.

EQ-004 Canonical Text и Canonical Diagram должны представлять одну
и ту же семантику.

EQ-005 Эквивалентность не требует совпадения идентификаторов элементов.

## Non-goals

- алгоритмы сравнения;
- вычисление различий;
- оптимизация проверки.

## Rationale

Понятие эквивалентности необходимо для совместимости независимых
реализаций и безопасного обмена моделями.
