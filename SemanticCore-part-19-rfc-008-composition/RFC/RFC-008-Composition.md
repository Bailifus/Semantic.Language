# RFC-008: Composition

Status: Draft

## Purpose

Определить правила композиции семантических примитивов.

## Scope

Документ определяет только правила построения корректной Semantic Model.

## Definition

Композиция представляет собой процесс объединения примитивов Semantic Core
в единую согласованную Semantic Model.

## Normative Requirements

CP-001 Semantic Model должна состоять только из допустимых примитивов.

CP-002 Statement связывается с Entity исключительно через Statement Instance.

CP-003 Все ссылки внутри модели должны быть адресуемыми.

CP-004 Композиция не должна изменять семантику входящих примитивов.

CP-005 Независимые части модели могут композиционно объединяться без изменения их локальной семантики.

## Non-goals

- оптимизация хранения;
- физическая реализация;
- распределённые модели.

## Rationale

Единые правила композиции обеспечивают совместимость независимых реализаций.
