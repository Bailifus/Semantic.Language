# RFC-010: Canonical Diagram

Status: Draft

## Purpose

Определить требования к производному графическому представлению Canonical Text.

## Scope

Документ описывает только Canonical Diagram.
Стиль оформления, компоновка и средства визуализации не рассматриваются.

## Definition

Canonical Diagram — производное графическое представление Canonical Text,
предназначенное для визуального восприятия модели и не являющееся независимым
источником нормативной семантики.

## Normative Requirements

CD-001 Каждый Canonical Diagram должен быть построен из Canonical Text.

CD-002 Canonical Diagram должен содержать достаточно информации для
восстановления семантически эквивалентного Canonical Text.

CD-003 Визуальный стиль, компоновка и порядок отображения не должны влиять на
семантику модели.

CD-004 Canonical Diagram не должен дополнять, изменять или переопределять
Canonical Text. При любом расхождении приоритет имеет Canonical Text.

CD-005 Преобразование Canonical Text в Canonical Diagram и обратно не должно
приводить к потере семантики.

## Non-goals

- независимое определение семантики;
- эстетика оформления;
- автоматическая компоновка;
- цветовые схемы;
- редакторы диаграмм.

## Rationale

Canonical Diagram предоставляет единое графическое средство восприятия
Canonical Text, сохраняя текст как единственный нормативный источник
сериализованной семантики.
