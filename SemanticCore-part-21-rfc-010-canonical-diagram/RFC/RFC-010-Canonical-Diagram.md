# RFC-010: Canonical Diagram

Status: Draft

## Purpose

Определить требования к каноническому графическому представлению Semantic Model.

## Scope

Документ описывает только каноническую диаграмму.
Стиль оформления и средства визуализации не рассматриваются.

## Definition

Canonical Diagram — нормативное графическое представление Semantic Model,
достаточное для полного восстановления её семантики.

## Normative Requirements

CD-001 Каждый семантический элемент должен иметь однозначное графическое представление.

CD-002 Диаграмма должна содержать всю семантически значимую информацию.

CD-003 Визуальный стиль не должен влиять на семантику модели.

CD-004 Эквивалентные Semantic Model должны иметь канонически эквивалентные диаграммы.

CD-005 Преобразование между Canonical Diagram и Canonical Text не должно приводить к потере семантики.

## Non-goals

- эстетика оформления;
- автоматическая компоновка;
- цветовые схемы;
- редакторы диаграмм.

## Rationale

Каноническая диаграмма обеспечивает единое графическое представление модели
для независимых реализаций и инструментов.
