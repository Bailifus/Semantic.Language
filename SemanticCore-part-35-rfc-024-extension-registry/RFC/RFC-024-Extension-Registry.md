# RFC-024: Extension Registry

Status: Draft

## Purpose

Определить требования к реестру расширений Semantic Core.

## Scope

Документ определяет правила публикации информации о расширениях.

## Definition

Extension Registry — каталог расширений, содержащий сведения,
необходимые для их идентификации и совместного использования.

## Normative Requirements

ER-001 Каждое расширение должно иметь уникальный идентификатор.

ER-002 Для каждого расширения должна быть указана его спецификация.

ER-003 Реестр должен содержать сведения о совместимости расширения.

ER-004 Отсутствие записи в реестре не запрещает использование расширения.

ER-005 Semantic Core не регламентирует форму реализации реестра.

## Non-goals

- централизованное управление;
- процесс регистрации;
- лицензирование;
- механизм распространения.

## Rationale

Реестр упрощает обмен информацией о расширениях между независимыми
реализациями без создания обязательной централизованной инфраструктуры.
