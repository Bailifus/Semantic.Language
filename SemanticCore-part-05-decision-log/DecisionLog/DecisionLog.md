# Decision Log

## DEC-001 Minimal Semantic Core
Решение:
Ядро должно содержать минимально необходимое количество примитивов.

Причина:
Упростить независимые реализации и исключить дублирование возможностей.

---

## DEC-002 Separation of Concerns
Решение:
Семантика, представление и теория разделяются.

Причина:
Каждый уровень должен эволюционировать независимо.

---

## DEC-003 Role Receives a Value
Решение:
Фундаментальной операцией является присвоение значения роли:
StatementInstance.Role = Value.

Причина:
Это единообразно описывает любые утверждения.

---

## DEC-004 Statement About Statement
Решение:
Значением Role может быть Statement Instance.

Причина:
Это позволяет естественно моделировать утверждения об утверждениях.

---

## DEC-005 Identity Outside Core
Решение:
Идентичность, эквивалентность и уникальность не входят в Semantic Core.

Причина:
Эти понятия определяются конкретной Theory.

---

## DEC-006 No OOP Concepts
Решение:
Классы, наследование и аналогичные конструкции не являются примитивами Semantic Core.

Причина:
Они относятся к отдельным теориям моделирования, а не к универсальной семантике.

---

## DEC-007 Canonical Representations
Решение:
Канонический текст и каноническая диаграмма считаются эквивалентными представлениями модели.

Причина:
Смысл хранится только в Semantic Model.

---

## DEC-008 Value Has No Intrinsic Semantics
Решение:
Semantic Core рассматривает Value только как объект, назначенный Role в
Statement Instance. Внутренняя семантика Value не является свойством Core и
выражается посредством других Statement Instance.

Причина:
Это сохраняет предметную нейтральность Core и не вводит скрытый канал
семантики вне Statement.

---

## DEC-009 No Implicit Statement Instances
Решение:
Statement Instance не возникает только потому, что для некоторого Statement
можно построить корректное назначение Values его Roles. Оно вводится только
тогда, когда корректно относительно Statement и действительно участвует в
Semantic Model как выраженный факт либо как Value другого Statement Instance.

Причина:
Не порождать семантические объекты, которые модель не использует, и отделить
возможность построения экземпляра от его существования в модели.
