# RFC-012: Extension Model

Status: Draft

## Purpose
Определить правила расширения Semantic Core без нарушения совместимости.

## Scope
Документ описывает требования к расширениям Semantic Core.

## Definition
Extension — дополнительная функциональность, построенная поверх Semantic Core и не изменяющая его нормативную семантику.

## Normative Requirements

EX-001 Расширение не должно изменять смысл существующих примитивов.

EX-002 Реализация без поддержки расширения должна сохранять корректную интерпретацию базовой Semantic Model.

EX-003 Расширение должно быть явно идентифицируемо.

EX-004 Расширение может вводить новые конструкции только через Theory или Presentation.

EX-005 Несколько независимых расширений должны иметь возможность сосуществовать.

## Non-goals

- механизм загрузки расширений;
- управление зависимостями;
- версии расширений;
- модель плагинов.

## Rationale
Совместимость достигается за счёт сохранения неизменного ядра.
