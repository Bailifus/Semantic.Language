# RFC-023: Capability Discovery

Status: Draft

## Purpose

Определить единый механизм публикации поддерживаемых возможностей реализации.

## Scope

Документ определяет только состав публикуемой информации.

## Definition

Capability Discovery — стандартизованный способ сообщить другой реализации,
какие возможности Semantic Core поддерживаются.

## Normative Requirements

CDS-001 Реализация должна иметь возможность сообщить поддерживаемую версию спецификации.

CDS-002 Реализация должна иметь возможность сообщить поддерживаемые RFC.

CDS-003 Реализация должна иметь возможность сообщить поддерживаемые профили.

CDS-004 Реализация должна иметь возможность сообщить поддерживаемые расширения.

CDS-005 Формат публикации возможностей не регламентируется Semantic Core.

## Non-goals

- сетевые протоколы;
- API обнаружения;
- механизмы авторизации;
- транспорт.

## Rationale

Стандартизованное описание возможностей позволяет независимым реализациям
автоматически определять уровень совместимости.
