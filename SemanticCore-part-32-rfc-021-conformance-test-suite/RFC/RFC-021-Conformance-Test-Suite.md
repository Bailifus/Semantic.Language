# RFC-021: Conformance Test Suite

Status: Draft

## Purpose

Определить требования к набору тестов, подтверждающих соответствие реализации
спецификации Semantic Core.

## Scope

Документ описывает требования к тестам, а не к их реализации.

## Definition

Conformance Test Suite — стандартизованный набор проверок,
подтверждающих выполнение нормативных требований RFC.

## Normative Requirements

TS-001 Каждый нормативный пункт RFC должен иметь возможность проверки.

TS-002 Каждый тест должен быть однозначно связан с одним или несколькими
нормативными требованиями.

TS-003 Результат выполнения теста должен быть воспроизводим.

TS-004 Невыполнение обязательного теста означает несоответствие реализации
соответствующему требованию.

TS-005 Структура тестового набора не регламентирует способ реализации тестов.

## Non-goals

- язык тестирования;
- автоматизация;
- CI/CD;
- сертификация.

## Rationale

Наличие стандартного тестового набора делает заявления о соответствии
объективно проверяемыми независимо от реализации.
